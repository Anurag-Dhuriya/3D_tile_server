Blender
Check if Blender exists at the path your server uses:

/Applications/Blender.app/Contents/MacOS/Blender --version
If it says file not found, install Blender:

brew install --cask blender
Then test again:

/Applications/Blender.app/Contents/MacOS/Blender --version
3d-tiles-tools
Check if installed:

which 3d-tiles-tools
3d-tiles-tools --version
If it says command not found, install Node.js first:

brew install node
Then install 3d-tiles-tools:

npm install -g 3d-tiles-tools
Then verify:

which 3d-tiles-tools
3d-tiles-tools --version
After both work, start your server:

Then start fresh:

source venv/bin/activate
python3 server.py
If needed, trigger only new_model:

curl -X POST http://localhost:8080/api/models/new_model/process
Check status:

curl http://localhost:8080/api/models/new_model/status
